広島市・税関係の様式ページ（約159件。一部は要約から数えたので概数）

| 形式 | 件数 | 割合 |
|---|---|---|

**Excelで配られている様式は全体の4分の1。そのうち8割近くが旧形式の .xls。**
masume が届くのは今のところこの4分の1だけ。.xls は `masume convert`（ExcelかLibreOfficeが必要）を経由する。
「記入できるExcel様式が欲しい人」には十分だが、「役所の書類を楽に出したい人」全体から見ると、入口が狭い。

### 1回目で見つかり、直したもの

- □の欄の読み戻しの不具合（空文字が「印あり」と判定されていた）。Python版とブラウザ版の両方にあった古いバグ
- 印字（問い合わせ先・縦書きの見出し）を入力欄として出さない
- `令和` という id だった欄を `年度` にする
- warning を追加：マス数より文字が少ない（左詰め）、元号が印字されていない欄に和暦の年を書いた
- 分割欄の表示を、様式と同じ見た目にする：`（[M42]）[Y42]－[AQ42]`、`令和[E15]年[I15]月[M15]日`
- SKILL.md に追記：`verified` の意味、warning を必ず伝える、記入要領を読む、聞いていない事実は推測せず確認する

## 機能がそろっているか（利用者の仕事の流れで点検）

| 段階 | 状態 | 足りないもの |
|---|---|---|
| 様式を手に入れる | .xlsx ○、.xls △（変換が必要）、**PDF ×、Word ×** | 様式の約7割を占めるPDFに未対応 |
| 欄を理解する | ○（md・inspect・ブラウザ版） | 大きな様式（異動届の下半分）、数値の明細は手直しが必要 |
| 事実を集める | △ | **会社情報（社名・所在地・法人番号・担当者）を毎回入力している**。2様式とも同じ情報を入れた |
| 記入する | ○（壊さない・Excelで確認済み） | — |
| 確かめる | △ | テキストの読み戻しのみ。**記入後の見た目（印刷イメージ）を確認する手段がない**（Excelが入ったWindowsならPDF出力で確認できる） |
| 印刷・提出する | △ | 長い住所が枠からはみ出しても気づけない |
| 次回も使う | △ | fields.json の保存・再利用はできる。様式ごと・会社ごとの保存場所は決まっていない |
